# 🃏 Jokes Viewer Application

A sleek, modern React application that delivers a dose of humor at the click of a button. Built with a focus on **Rich Aesthetics** and a seamless user experience.

![Project Preview](./preview.png)

## ✨ Features

- **Random Joke Generation**: Instantly fetch and display random jokes from a public API.
- **Glassmorphic UI**: High-end design featuring frosted glass effects, sleek gradients, and modern typography.
- **Full Responsiveness**: Optimized for both desktop and mobile devices.
- **Interactive Animations**: Smooth transitions and hover effects for an engaging experience.

## 🚀 Tech Stack

- **Frontend**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Modern CSS3 with Flexbox & Glassmorphism)
- **API**: [FreeAPI](https://freeapi.app/)

## 🛠️ Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rahulverma307/Jokes_Viewer_Application.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Jokes_Viewer_Application
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:5173`.

## 📖 Key Components

- **`App.jsx`**: Manages the state for jokes and handles API fetching logic using the `useEffect` hook.
- **`App.css`**: Contains the custom design system, utilizing HSL colors, backdrops, and gradients for a premium feel.
